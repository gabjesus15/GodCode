# Leaked Password Protection (Supabase Auth)

Checklist para cerrar el hallazgo `auth_leaked_password_protection` del advisor de seguridad:

1. Supabase Dashboard → tu proyecto.
2. **Authentication** → **Security** (o **Providers** según UI).
3. Activar **Leaked Password Protection** / integración con Have I Been Pwned.

Sin cambios en este repositorio; es configuración del proyecto en la nube.
